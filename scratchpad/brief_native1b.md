## The work
1. **The ladder.** For every library mesh, build a cluster hierarchy from full detail down: level 0 = the full-detail clusters as 1a emits them (16 tris, <= 48 verts each); each coarser level = groups of clusters simplified together (the existing meshopt simplification, locked borders between groups so no crack -- state the grouping rule), until one cluster remains or the error stops growing. Every cluster row gains `geometricError` (f32, world units: the maximum deviation of the simplified surface from the FULL-detail surface, not from the parent -- so errors are monotone up the ladder and a consumer compares one number against one tolerance), `parentFirst`/`parentCount` (or a group id -- state the law), `level` (u8). The ladder's memory: `.lodo` header 0xC0-0xFF for the offsets (section 12); the cluster table grows or a parallel table is added -- state which and why. Monotonicity is a REFUSAL: a child with a larger error than its parent is refused by name.
2. **Cluster bounds and cones.** Per cluster: bounding sphere (centre f32[3], radius f32) and a normal cone (axis as octahedral-encoded u16x2 or f32[3], half-angle cosine f32, or the "cone is open" flag when the cluster's normals span more than a hemisphere -- leaf cards and double-sided shapes). Flag bits 2-15 are named in section 12. Gate: every triangle of a cluster lies inside its sphere (+1e-3), every face normal within the cone (a cone that would exclude one of its own triangles is refused), floors = a deliberately shrunk sphere and a deliberately narrowed cone shown red.
3. **Occluder boxes per cell.** From the region's placements, for each cell: up to N (state N; 4 is a sane start) oriented boxes fitted inside the largest solid objects (buildings, rocks, large walls: a box is only an occluder if it lies INSIDE the mesh -- an occluder that sticks out of its object hides things wrongly, which is worse than no occluder). Written to the `.lodi` (header 0x98-0xFF for the table offset). Gate: for every box, 100 random points inside it are inside the source mesh (winding-number or ray-parity test), floor = a box grown by 10 percent shown red; the census prints boxes per cell and the fraction of cells with none.
4. **The selection law, stated for the reader** in the contract (section 4.4 extends): `screenErrorPx = geometricError x scale x projectionScale / distance`, cluster drawn if its own error <= tolerance AND its parent's error > tolerance (the standard cut), the shadow view using the same law with its own tolerance. A tiny reference selector in the decoder (`tests/spells/lodgen_native_decode.py` or a sibling) that, given a camera and a tolerance, produces the cut and asserts it is a partition of the surface (every full-detail triangle covered exactly once by the cut's clusters' ancestry), on the real pair, for three tolerances (0.5, 1, 4 px) and two distances; the triangle counts printed per case, with the floor that tolerance 0 selects level 0 only and a huge tolerance selects the root only.
