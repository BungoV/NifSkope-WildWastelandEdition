1Solid collision display

Translucent fill (~30 % alpha, unlit, depth-write off, backfaces darker) + full-alpha wire overlay. Reads as a synthetic shell next to lit BSTriShapes — never confusable. X-ray shows shells through geometry; Collision only hides render meshes. Material labels (Off / Selected / All): dot + name at each shell, halo text, auto-hidden for shapes too small on screen so the viewport never clutters.

2One hue, four meanings — a mode

Colour by Material (default), Layer, State, or Type. Fill hue carries the mode; the wire always encodes shape type (white box, yellow hull, cyan capsule, magenta mesh), so type stays readable in every mode.

3Browser = the truth table

One row per body (the Body ID binding we validated). Swatches double as the legend, eye toggles per-shape visibility, chips show COMPILED vs EDITABLE. Selecting a row selects the block and highlights the shell.

4Create from BSTriShape

Six fits — Box, Sphere, Capsule, Hull, CoACD decomposition, tri-mesh. Material is a search field: type a full or partial name and the 157-entry list filters live; an unmatched name becomes a valid custom material (CRC32 of the name) and is remembered. 💾 saves the whole setup — coll type + material + physics — as a named preset. The BSTriShape → Collision / Collision → BSTriShape pair is the round trip. Presets write the validated authoring values (dynamic 3/4/2, static 5/0/1).

5Physics, 3ds-Max parity

Every field we decode — mass, friction, restitution, damping, velocities, layer, material, motion/quality — live-edits the legacy body. Compiled rows grey out with a one-click Decode to edit.

6Compile — no Elric

hknpencode packs the legacy tree straight into a bhkPhysicsSystem packfile (PyNifly-proven format + our corrections), one body per node, Body IDs wired. Validated by round-tripping the controlled pairs and FileConvert-as-linter.

7Status readout & transforms

Selecting collision anywhere shows a one-line readout in the bottom bar — node, shape, collision type, material, state, mass, friction. And collision transforms like a BSTriShape: G/R/S in the viewport writes to the owning node (whole body), the transform-shape wrapper (sub-shapes), or shape fields (primitives). Compiled shells prompt Decode to edit.
