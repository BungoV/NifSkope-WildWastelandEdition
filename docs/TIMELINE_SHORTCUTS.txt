NifSkope Timeline - keyboard and mouse reference
=================================================
(The timeline dock must have focus for keyboard shortcuts; click it first.)

PLAYBACK
  Space               Play / pause (animation must be enabled in the toolbar)
  Home                Frame all (zoom to fit every key)
  F  /  Numpad .      Frame selected keys (or current lane)
  End                 Jump playhead to the end
  ,  /  .             Step playhead to previous / next key of the selected lane
  Ctrl+,  /  Ctrl+.   Jump to previous / next text key marker

VIEW
  Ctrl+Mouse wheel    Zoom the time axis around the cursor (lanes pane)
  Mouse wheel         Scroll lanes (lanes pane) / zoom (graph pane)
  Drag the label/time divider   Resize the name column
  Toolbar [sec]/[fps] Toggle seconds/frames ruler (right-click it to pick fps)
  Toolbar magnet      Toggle snapping; the two spinboxes are time and value steps

SELECTION
  Click key           Select key (shows it in Block Details and the inspector)
  Shift+Click key     Add/remove key from the selection
  Drag on empty lane area        Rubber-band select keys across lanes
  Shift+Drag in graph            Rubber-band select in the graph
  Click summary row   Select all keys at that time column across lanes
  Escape              Clear key selection

EDITING
  Drag key            Move in time (lanes) / time + value (graph); snapping applies
  Drag tangent handle Adjust quadratic tangents of the primary selected key (graph)
  Double-click lane/graph        Insert a key at that time (value sampled from curve)
  I                   Insert key at the playhead on the selected lane
  Delete / Backspace  Delete selected keys
  Shift+D             Duplicate selected keys (offset by one snap step)
  Ctrl+C / Ctrl+V     Copy selected keys / paste at the playhead
  S                   Scale selected key times around the playhead (prompts for factor)
  Arrow Left/Right    Nudge selected keys in time by one snap step
  Arrow Up/Down       Nudge selected key values by one value step (scalar channels)
  Ctrl+Z / Ctrl+Y     Undo / redo (all timeline edits are undoable)

RULER
  Drag                Scrub the playhead
  Shift+Drag          Set the preview/loop range (playback loops inside it)
  Right-click         Add text key marker here / clear preview range

LANES
  Click lane          Select lane + its block in the tree; curves appear in the graph
  Click speaker icon  Mute/unmute (toggles the controller's Active flag)
  Right-click lane    Context menu: insert/delete/clear keys, easing presets,
                      interpolation type, channel copy/paste, CSV export/import,
                      lane display mode (diamonds/sparkline/strip), lock, mute
  Key marker shapes   Diamond = linear, Circle = quadratic, Square = constant

VIEWPORT
  Alt+Q               Solo mode: render only the selected node's subtree
                      (also in Render menu; follows the selection while enabled)

BLOCK LIST (right-click a node/shader/property)
  Animation > Setup Controllers...      Attach controllers, wire into a sequence,
                                        palette + multi-target handled automatically
  Animation > Remove From Animation...  Delete a node's animation wiring selectively
  Animation > Duplicate Sequence...     Deep-copy a NiControllerSequence
  Animation > Scale Sequence Times...   Stretch/compress a whole sequence
  Animation > Bake B-Spline To Keys...  Convert a B-spline interpolator to keyframes

TIMELINE TOOLBAR
  Checkmark button    Animation lint: finds broken node names, missing palette
                      entries, out-of-range keys, missing start/end text keys etc.
                      Double-click a finding to jump to it; name mismatches offer a fix.
  Target button       Filter lanes to the selected geometry node
  Sidebar button      Show/hide the inspector panel

  Shift+Space        Play backward (timeline focused)

  Sequence headers   All-controllers view groups each sequence; click header to fold

VIEWPORT TRANSFORM GIZMO (Blender style, viewport focused, node selected)
  G / R / S          Start move / rotate / scale (modal)
  X / Y / Z          Constrain to axis (rotate default: view axis; scale is uniform)
  Mouse move         Apply transform live      Shift = precision
  Ctrl               Snap: grid step (Render > Gizmo Snap Distance...), 5 deg, 0.1x
  LMB / Enter        Commit (single undo step)
  RMB / Esc          Cancel
  Space              Play/pause animation (viewport focused)
  Render menu        Auto-Key Transforms: keys each committed transform at the playhead

NEW SPELLS
  Animation > Sort By Node Name        on Controlled Blocks of a sequence
  Animation > Sort By Name             on Objs of an object palette
  Animation > Generate BSPositionData  on FO4 geometry (particle spawn positions)
  Block > Replace References With...   repoint every reference to another block
                                       (type an index or name to filter, sortable)

ADDED IN THE 2026-07-05 UPDATE
  Timeline toolbar   New buttons: prev/next keyframe, loop + switch animation
                     (mirrored from the render toolbar); all icons redrawn
  Combo renames      "All animations" / "Loose animations"
  Key click          Unrolls that key (and only that key) in Block Details

TRANSFORM GIZMO 2.0 (viewport)
  Draggable handles  Arrows = move, rings = rotate, boxes = scale,
                     center dot = view-plane move; hover highlights,
                     drag commits one undo step
                     (Render > Show Transform Gizmo toggles them)
  Numeric input      During G/R/S just type: R Y 45 [Enter] = rotate 45 deg
                     around Y; G X 12.5 = move 12.5 units; S 2 = double size
                     Tab cycles X/Y/Z parts on unconstrained moves,
                     minus toggles sign, Backspace edits
  Redo panel         After a transform, a small panel appears bottom-left:
                     edit the offsets/angle/factor numerically, same undo step
  Render menu        Transform Orientation: Global / Local / Parent / View
                     Transform Pivot Point: Node Origin / Bounding Center /
                     Picked Elements Median / 3D Cursor
                     Snap Target (Ctrl): Grid Step / Vertex / Edge / Face,
                     Align Rotation to Target, Rotation Snap Angle...

ELEMENT SELECT, EDIT + 3D CURSOR (viewport)
  1 / 2 / 3          Toggle vertex / edge / face pick mode (Blender style)
  Click              Pick the element under the mouse (highlighted)
  Shift+Click        Add/remove from the multi-selection (median shown)
  G / R / S          Move / rotate / scale the picked elements (same modal
                     rules as node transforms: X/Y/Z, numeric, Ctrl snap,
                     LMB commit, Esc/RMB cancel) around their median or cursor
  Delete / X         Delete picked vertices/edges/faces from the mesh
  Esc                Clear picked elements
  C                  Place the 3D cursor on the surface under the mouse
  Shift+C            Snap the cursor to the picked elements' median
  Render > 3D Cursor & Elements   Snap cursor to picked/origin,
                     snap node to cursor, move picked vertices to cursor
                     (vertex editing, undoable), show/hide cursor

TOOLBAR + CAMERA
  Icons              Main toolbar icons scaled down; view directions, display
                     toggles and dock panels each merged into one dropdown;
                     a Blender-style transform header (orientation, pivot,
                     magnet, snap target, element select, gizmo, cursor)
  Shift+F            Toggle free camera: WASD/Q/E/arrows/PgUp-Dn move the
                     camera only while enabled (so the letters stay free for
                     transforms); outside it, orbit/pan with the mouse
  Gizmo & Cursor Size   Render menu; also Show Transform Gizmo toggle

SPELLS (top bar)
  Spells > Textures > Material / Texture Manager...   list + edit every
                     material and texture path, with find & replace
  Right-click node > Rename (sync animation)...   rename and keep the palette
                     and controller sequences in sync
  Spells > Animation > Enforce Node Name Authority   resync every palette and
                     sequence name to its node

PARTICLE PREVIEW

  (preview-grade): box/cylinder/sphere/mesh/array emitters incl.
  BSPositionData spawn points, birth rate + emitter-active controllers,
  gravity, drag, 3-color ramp, scale curve. Play or scrub the animation
  to drive it; scrubbing backwards restarts the simulation.
