Block Details Overhaul v2 — revised mockup, NifSkope visual language.

Everything is the existing vocabulary: the two-column Name | Value tree with alternating rows, section rows that expand/collapse exactly like compound rows do today, flat auto-raise buttons (the Block List header kind), grey secondary text, and the Shader Flags dialog's styling. No cards, no pills, no colored chips.

New behavior hides until needed: row buttons (↗ jump, ▾ pick, ★ pin) appear on hover at the row's right edge; scrubbable numbers are marked only by a dotted underline; the header is two quiet text lines — breadcrumb and summary — plus one flat button row.
